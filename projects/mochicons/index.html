About

mochicons is a collection of hand-made SVG icons that you can use in your web projects. Every icon is designed on a 24×24 grid with a 2px stroke and a minimum padding of 2px, so they all feel like part of the same family. Each icon is a single <svg> with a single <path>, drawn with currentColor, which makes them easy to copy, tweak and restyle.

Features

Multiple formats
React components, CSS classes, SVG sprite and JSON metadata, all in a single package.
Consistent design
A clean 24×24 grid, a 2px stroke and rounded joins give the whole set a coherent look.
Easy to customize
Control the size, color and stroke width of any icon, in React props or plain CSS.
Free to use
Public domain icons, MIT code. No restrictions, no attribution.

Installation and usage

Add mochicons to your project using a package manager like npm:

$ npm add mochicons

You can use them as React components:

import { AccessPointIcon } from "mochicons/react";

const MyComponent = () => (
    <div style=>
        <AccessPointIcon />
    </div>
);
